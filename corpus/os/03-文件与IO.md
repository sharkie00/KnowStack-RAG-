# 操作系统笔记 · 文件与 I/O

## 3.1 页缓存

页缓存是内核用来缓存文件页的内存区域。read/write 会经过页缓存，mmap 把文件页直接映射到进程地址空间。

页缓存和虚拟内存共用物理页框管理：文件页被读入页缓存后，再由页表映射到进程。脏页由回写线程刷盘，内存压力下会被回收。

## 3.2 系统调用

系统调用是用户态程序请求内核服务的唯一入口。执行系统调用时，CPU 从用户态陷入内核态，保存现场，切换内核栈，执行服务例程，再返回用户态。

系统调用比普通函数调用慢，因为涉及特权级切换、现场保存、参数校验，还可能污染 TLB 和缓存。

## 3.3 缓冲与零拷贝

标准 I/O 通常有用户缓冲区和内核页缓存两次拷贝。mmap 和 sendfile 可以减少拷贝次数。

例如，发送文件时用 sendfile 可以直接从页缓存送到网卡，避免用户态中转。
