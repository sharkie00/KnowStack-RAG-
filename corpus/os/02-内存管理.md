# 操作系统笔记 · 内存管理

## 2.1 虚拟内存

虚拟内存为每个进程提供独立的地址空间，把逻辑地址转换为物理地址。页表保存页号到页框号的映射。

页表项有效位为 1 表示该页不在内存。访问不在内存的页会触发缺页中断。

## 2.2 TLB

TLB 是页表项的缓存，通常位于 MMU 中。地址转换时先查 TLB，命中则直接得到页框号，未命中再查页表。

例如，连续访问同一页的多个变量时，第一次未命中，后续都命中，因此很快。

## 2.3 多级页表

多级页表把逻辑地址拆成多个索引段，只为实际使用的地址区间分配下级页表。稀疏地址空间下可以节省大量页表内存。

代价是地址转换需要多次访存，TLB 命中可以减少开销。

## 2.4 缺页中断

缺页中断的处理流程：

1. 访问页表，发现有效位为 0，触发缺页异常。
2. 陷入内核，检查地址是否合法。
3. 选择一个牺牲页，若为脏页则写回磁盘。
4. 从磁盘调入所需页，更新页表和 TLB。
5. 返回用户态，重新执行触发缺页的指令。

## 2.5 页面置换与 LRU

常见页面置换算法有 OPT、FIFO、LRU。OPT 淘汰未来最久不用的页，无法实现，只用于理论比较；FIFO 实现简单，但可能出现 Belady 异常；LRU 淘汰最久未使用的页，局部性好时效果接近 OPT。

LRU 可以用哈希表加双向链表实现 O(1)：

```python
class LRU:
    def __init__(self, cap):
        self.cap = cap
        self.map = {}
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def get(self, key):
        if key not in self.map:
            return -1
        node = self.map[key]
        self._move_to_head(node)
        return node.value

    def put(self, key, value):
        if key in self.map:
            node = self.map[key]
            node.value = value
            self._move_to_head(node)
            return
        if len(self.map) == self.cap:
            node = self.tail.prev
            self._remove(node)
            del self.map[node.key]
        node = Node(key, value)
        self.map[key] = node
        self._add_to_head(node)
```
