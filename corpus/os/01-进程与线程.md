# 操作系统笔记 · 进程与线程

## 1.1 进程与线程的区别

进程是资源分配的基本单位，线程是 CPU 调度的基本单位。一个进程可以包含多个线程，同一进程内的线程共享地址空间、打开的文件和全局变量，但每个线程有独立的栈、寄存器和程序计数器。

例如，浏览器的一个标签页可以看作一个进程，页面渲染、网络请求、脚本执行分别由不同线程完成。

进程和线程的主要区别：

- 资源：进程有独立地址空间，线程共享所属进程的地址空间。
- 开销：进程切换需要切换页表，线程切换通常不需要。
- 通信：线程间通信更简单，进程间需要管道、共享内存等机制。

## 1.2 上下文切换

上下文切换保存当前任务的寄存器、程序计数器和栈指针，再恢复下一个任务的现场。

进程切换不会切换页表，因为同一进程的线程共享地址空间。

线程切换比进程切换便宜，主要原因是线程共享页表，不需要刷新 TLB。

## 1.2.1 一个上下文切换的例子

例如，同一进程内的线程 A 切换到线程 B 时，需要保存 A 的寄存器、程序计数器和栈指针，再恢复 B 的现场；如果切换到另一个进程，还要保存和恢复地址空间相关的状态。

## 1.3 死锁

死锁是指多个进程互相等待对方持有的资源，导致都无法继续执行。

死锁的四个必要条件：

1. 互斥：资源一次只能被一个进程占用。
2. 占有并等待：进程持有资源的同时等待其他资源。
3. 不可剥夺：资源不能被强制抢占。
4. 循环等待：存在进程与资源的环形等待链。

例如，进程 A 持有打印机等待扫描仪，进程 B 持有扫描仪等待打印机，就形成循环等待。

## 1.4 信号量

信号量是一个整型变量，配合 P（wait）和 V（signal）操作实现同步与互斥。P 操作将信号量减一，若小于零则阻塞；V 操作加一并唤醒等待者。

生产者—消费者用 mutex 保护缓冲区，用 empty 和 full 计数：

```python
sem = Semaphore(1)
empty = Semaphore(N)
full = Semaphore(0)

def producer():
    while True:
        item = produce()
        empty.P()
        sem.P()
        buffer.append(item)
        sem.V()
        full.V()

def consumer():
    while True:
        full.P()
        sem.P()
        item = buffer.pop(0)
        sem.V()
        empty.V()
        consume(item)
```

必须先 P(empty/full) 再 P(mutex)，否则缓冲区满或空时会持有锁睡眠，导致死锁。

## 1.5 僵尸进程与孤儿进程

僵尸进程是已经退出但父进程还没有调用 wait 回收的进程。它不占内存，但占用进程表项。

孤儿进程是父进程先退出、被 init 或收养进程接管的进程。
